# RedfireForge Homebrew Tap

This is the official [Homebrew](https://brew.sh) tap for [RedfireForge](https://redfireforge.com).

## Install

```bash
brew tap redfireforge/tap
brew install --cask redfireforge
```

Or as a one-liner:

```bash
brew install --cask redfireforge/tap/redfireforge
```

## Update

```bash
brew upgrade --cask redfireforge
```

## Uninstall

```bash
brew uninstall --cask redfireforge
```

## About RedfireForge

Visual API testing and load-testing workbench for HTTP, GraphQL, gRPC, WebSocket, SSE, and Kafka.
Includes a workflow designer, built-in mock server, and CLI. Free and open source.
